# CC 攻击工具 DoS_cc_Attack_Tool

> 作者：polar bear  
 > 适用场景：HTTP/HTTPS 应用层压力测试、CC 攻击模拟

## 📖 原理

CC（Challenge Collapsar）攻击是一种应用层 DDoS 攻击。
工具通过大量 HTTP/HTTPS 请求（GET/POST）耗尽目标服务器的 CPU、内存或数据库连接资源，导致正常用户无法访问。
本工具基于多线程技术，支持随机 User-Agent、随机延迟、代理池轮换，模拟真实用户行为。

## 🎯 功能

- ✅ 多线程 HTTP/HTTPS 洪水（原版逻辑：随机延迟、成功/失败日志）
- ✅ 深度扫描目标（检测响应时间、动态参数、表单、Cloudflare、WAF）
- ✅ 一键自动推荐线程数和代理策略
- ✅ 代理池支持（从 `proxies.txt` 加载，攻击时随机轮换）

## 🚀 使用方法

### 1. 运行
- 双击 `CC_Attack_Tool.exe`（Windows）

### 2. 操作步骤
1. **同意免责协议**：启动后弹出协议窗口，点击“是”进入主界面。
2. **输入目标 URL**：例如 `http://example.com` 或 `https://example.com/api/login`。
3. **深度扫描**（可选）：点击“🔍 深度扫描并推荐”，工具自动分析目标特征并推荐线程数和代理配置。
4. **调整参数**：
   - 线程数：建议 100~800（上限 1000）
   - 请求间隔：0~10 秒，0 表示无延迟
5. **代理池**（可选）：
   - 勾选“启用代理池”
   - 点击“导入代理文件”，选择 `proxies.txt`（每行一个代理，格式 `ip:port` 或 `protocol://ip:port`）
6. **开始攻击**：点击“🔥 开始攻击”，攻击过程中可点击“停止攻击”终止。
7. **观察日志**：实时显示请求成功/失败信息。
